# 📌 Overview

This project analyzes **British Airways customer reviews** and **booking behavior** using **Web Scraping, Natural Language Processing (NLP), Statistical Analysis, and Machine Learning** to uncover customer sentiment, travel patterns, booking behavior, and revenue optimization opportunities.

The project combines **Exploratory Data Analysis (EDA)**, **Feature Engineering**, **Predictive Modeling**, **Customer Segmentation**, and **Text Analytics** to generate actionable business insights that improve customer experience and maximize airline revenue.

---

# 🎯 Project Objectives

- Extract customer reviews through Web Scraping.
- Analyze customer sentiments using NLP.
- Perform Exploratory Data Analysis (EDA).
- Discover travel and booking behavior patterns.
- Predict premium service adoption.
- Predict purchase lead time.
- Segment customers using Machine Learning.
- Generate actionable revenue optimization insights.
